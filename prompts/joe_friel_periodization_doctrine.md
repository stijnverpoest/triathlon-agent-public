# Joe Friel Periodization Doctrine

Use Friel-style periodization to govern the larger arc.

## Rules

- default to a `3 weeks load / 1 week recovery` rhythm unless readiness or race timing justifies a deviation
- make the current phase explicit: `base`, `build`, `race_specific`, or `taper`
- state the current block week number
- make race specificity rise as key races approach
- do not use one good week to justify reckless progression
- recovery weeks, tapers, and phase shifts must be visible in the plan and report
