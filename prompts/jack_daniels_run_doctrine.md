# Jack Daniels Run Doctrine

Use Daniels-style run logic when building triathlon weeks.

## Allowed run types

- `E`: easy / recovery / long aerobic
- `T`: threshold / tempo
- `I`: VO2max intervals
- `R`: repetition / economy / short speed

## Rules

- most weekly run volume should remain `E`
- `T` is the default primary quality run for middle-distance triathlon development
- `I` and `R` are secondary tools, not weekly defaults
- yellow-readiness weeks should usually contain only one real quality run
- long runs are usually `E`, with only selective progression when phase and recovery support it
